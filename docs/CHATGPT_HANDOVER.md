## What was built this session (all pushed)
- Quick UX: reset filters/sort/spin between rounds; picker search clears on close; per-player filters in pass-and-play; Goals+Putt on the green and Caps+Approach elsewhere; swap icon on the footballer chip; smaller aim arrow near the pin/when putting; picker star centred.
- Rules/difficulty: gimme distance measured from the cup EDGE; cup up to 6 ft (Settings shows feet); **gimme default is now 0 ft (hole-out only by physically dropping)** — the "next-shot gimme" idea was reverted; Round Setup Difficulty section (cup size, gimme, once-per-match vs once-per-mode footballer rule, wind, max score None/par+5/custom, aim aids, lie read-out Range/Exact, numbers on/off) frozen per round via `RoundConfig`; named local profiles with favourites; pass-and-play: furthest from the hole plays next.
- Lie penalties: rough 10-20%, bunker 20-40% shorter (flight shots, Caps or Goals); spin ball shows ground-level pixel-art lie with the penalty range or exact value (setting).
- Physics: cup rim lip-outs/skips, flagstick strikes, pin-assisted drops (`scripts/physics/ball_sim.gd`, `tests/integration/test_cup_flag.gd`).
- UI: post-shot result panel redesign (lie chip, divided metrics, Details/Continue, real score name on hole-out, HOLE COMPLETE banner, ring+spark effect at the cup, tap to skip); restyled Settings, tutorial, pause, confirm, developer panel; hole intro as a slim bottom bar over the bird's-eye view; ball on a tee peg; yellow tee markers; hold-to-fast-forward; drag up/down on aim view changes trajectory (trial, toggle); auto-continue after each offline shot with a progress bar (~2.5 s, toggle); between-hole/round-complete screens show the viewer's OWN scorecard with a tab per player.
- Graphics Tier 1 (merged): sky shader with sun halo/clouds, fog match, ground macro variation, per-hole sun/sky, Settings High/Low toggle (`docs/graphics/GRAPHICS_UPGRADE_PROPOSAL.md` lists Tier 2/3: hills, cloud shadows, birds, planes, wind-driven trees/flags, time of day, rain).
- Multiplayer: NO hosted relay. The host phone runs the relay itself (`scripts/network/local_relay.gd`, GDScript port of `relay/server.py`, port 8765). Hotspot-only flow: host taps Host, guest auto-finds the host by probing likely hotspot gateway addresses (`host_finder.gd`) and enters the room code; manual address fallback. Waiting phone sees the shooter's footballer, stat, shot type, trajectory, spin and live aim (preview messages), then the normal follow-camera replay. Docs: `docs/MULTIPLAYER.md`.
- Latest uncommitted-then-pushed WIP (`491eae9`): Pause button on the hole intro bar; online "Refresh" (intro bar + pause menu) that re-sends state (guest asks host through a new relay `resync` message).
